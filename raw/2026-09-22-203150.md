补充：# 长期记忆的保存方式、位置与格式

## 保存位置

长期记忆存放在 `codex_home` 下的 `memories` 目录,由 `memory_root()` 函数定义路径 [1](#2-0) 。该目录本身是一个 git 仓库(git-baseline 目录),初始化在 `~/.codex/memories/.git`,由 `codex-git-utils` 管理,用于追踪每次 Phase 2 整合前后的变更 diff [2](#2-1) 。

## 目录结构与文件格式

整合阶段的 prompt 模板明确规定了记忆文件夹结构:

| 文件/目录 | 用途 |
|---|---|
| `memory_summary.md` | 始终加载进 system prompt;第一行必须严格为 `v1`;需保持高密度、便于导航检索 |
| `MEMORY.md` | 手册条目;按关键词可 grep;聚合来自 rollout 的洞见;指向相关 rollout 摘要 |
| `raw_memories.md` | 临时文件:Phase 1 合并后的原始记忆,是 Phase 2 的输入 |
| `skills/<skill-name>/` | 可复用流程;入口文件 `SKILL.md`,可附带 `scripts/`、`templates/`、`examples/` |
| `rollout_summaries/<rollout_slug>.md` | 单次 rollout 的摘要,含教训、可复用知识、指针/引用和精简过的原始证据片段 | [3](#2-2) 

对应地,`lib.rs` 提供了这些路径的具体构造函数,例如 `rollout_summaries_dir`、`memory_extensions_root`、`raw_memories_file` [4](#2-3) ,并且 `ensure_layout` 在启动时创建根目录及 `rollout_summaries/` 子目录,同时移除任何指向记忆目录/文件的符号链接以防篡改 [5](#2-4) 。

## 具体保存格式

### `MEMORY.md`(手册)
每个记忆块必须以固定 header 开始:`# Task Group: ...`、`scope: ...`、`applies_to: ...`,body 部分按任务分组,含 `## Task <n>`(含 `### rollout_summary_files` 和 `### keywords`)、`## User preferences`、`## Reusable knowledge`、`## Failures and how to do differently` 等严格结构化小节 [6](#2-5) 。

### `memory_summary.md`(摘要,始终注入 prompt)
文件必须以精确的 `v1` 开头,紧接 `## User Profile` 小节;后续还包含 `## User preferences` 等结构化区块,要求高信号密度、去重严格 [7](#2-6) 。

### `skills/*`(可选)
每个技能是一个目录 `skills/<skill-name>/`,含必需入口 `SKILL.md`(YAML frontmatter + 指令),可选 `scripts/`、`templates/`、`examples/` [8](#2-7) 。

## 保存前的合法性校验

保存(即 Phase 2 整合)完成后,系统会调用 `validate_consolidation_artifacts_for_version` 校验产物是否合法:

- 确认没有残留符号链接
- V1 版本要求 `MEMORY.md` 存在且为普通文件
- 要求 `memory_summary.md` 首行严格为 `v1`
- V2 版本还需通过 `is_valid_v2_summary` 的额外 schema 校验 [9](#2-8) 

只有验证通过(`artifacts_valid == true`)后,`phase2::run` 才会重置 git baseline 并把任务标记为 `succeeded`,这是真正完成"保存"的时刻 [10](#2-9) 。

## 使用侧如何识别这些文件

在读取路径上,`codex-memories-read` crate 会根据文件路径分类记忆使用类型,支持 `MemoryMd`、`MemorySummary`、`RawMemories`、`RolloutSummaries`、`Skills` 五类,并区分 `memories/`(V1)与 `memories_v2/`(V2)两套目录 [11](#2-10) ,这印证了上面提到的文件/目录结构确实是运行时实际读取的路径。

## Notes

- `MEMORY.md` 只在 V1 版本中强制存在(见校验逻辑),V2 版本似乎主要依赖 `memory_summary.md` [12](#2-11) ;具体 V1/V2 差异的完整设计文档不在当前索引范围内,如需深入了解建议开启 Devin session。

pub async fn ensure_layout(root: &Path) -> std::io::Result<()> {
    tokio::fs::create_dir_all(root).await?;
    if tokio::fs::symlink_metadata(root)
        .await?
        .file_type()
        .is_symlink()
    {
        return Err(std::io::Error::new(
            std::io::ErrorKind::InvalidInput,
            format!("memory root cannot be a symbolic link: {}", root.display()),
        ));
    }

    workspace::remove_memory_symlinks(root).await?;
    tokio::fs::create_dir_all(rollout_summaries_dir(root)).await
}

/// Verifies that a completed consolidation run left the required memory artifacts in place.
pub async fn validate_consolidation_artifacts(root: &Path) -> anyhow::Result<()> {
    validate_consolidation_artifacts_for_version(root, MemoryVersion::V1).await
}

pub(crate) async fn validate_consolidation_artifacts_for_version(
    root: &Path,
    version: MemoryVersion,
) -> anyhow::Result<()> {
    let removed_symlinks = remove_memory_symlinks(root).await?;
    anyhow::ensure!(
        removed_symlinks == 0,
        "removed {removed_symlinks} symbolic links from consolidated memory workspace"
    );

    if version == MemoryVersion::V1 {
        let memory_path = root.join("MEMORY.md");
        let memory_metadata = tokio::fs::metadata(&memory_path).await.with_context(|| {
            format!(
                "read consolidated memory artifact {}",
                memory_path.display()
            )
        })?;
        anyhow::ensure!(
            memory_metadata.is_file(),
            "consolidated memory artifact is not a file: {}",
            memory_path.display()
        );
    }

    let summary_path = root.join("memory_summary.md");
    let summary = tokio::fs::read_to_string(&summary_path)
        .await
        .with_context(|| format!("read memory summary artifact {}", summary_path.display()))?;
    anyhow::ensure!(
        summary.lines().next() == Some("v1"),
        "memory summary artifact does not start with v1: {}",
        summary_path.display()
    );

    if version == MemoryVersion::V2 {
        anyhow::ensure!(is_valid_v2_summary(&summary), "invalid v2 memory summary");
    }
    Ok(())
}

#[derive(Clone, Copy, Debug, PartialEq, Eq, PartialOrd, Ord)]
pub enum MemoriesUsageKind {
    MemoryMd,
    MemorySummary,
    RawMemories,
    RolloutSummaries,
    Skills,
}

impl MemoriesUsageKind {
    pub fn as_tag(self) -> &'static str {
        match self {
            Self::MemoryMd => "memory_md",
            Self::MemorySummary => "memory_summary",
            Self::RawMemories => "raw_memories",
            Self::RolloutSummaries => "rollout_summaries",
            Self::Skills => "skills",
        }
    }
}

pub fn memories_usage_from_command(command: &str) -> Vec<(MemoriesUsageKind, MemoryVersion)> {
    let commands = parse_shell_script(command);
    if commands
        .iter()
        .any(|command| matches!(command, ParsedCommand::Unknown { .. }))
    {
        return Vec::new();
    }

    commands
        .into_iter()
        .filter_map(|command| match command {
            ParsedCommand::Read { path, .. } => get_memory_usage(path.display().to_string()),
            ParsedCommand::Search { path } => path.and_then(get_memory_usage),
            ParsedCommand::ListFiles { .. } | ParsedCommand::Unknown { .. } => None,
        })
        .collect()
}

fn get_memory_usage(path: String) -> Option<(MemoriesUsageKind, MemoryVersion)> {
    let path = path.replace('\\', "/");
    let version = if path.contains("memories_v2/") {
        MemoryVersion::V2
    } else {
        MemoryVersion::V1
    };
    let path = path.replace("memories_v2/", "memories/");
    let kind = if path.contains("memories/MEMORY.md") {
        MemoriesUsageKind::MemoryMd
    } else if path.contains("memories/memory_summary.md") {
        MemoriesUsageKind::MemorySummary
    } else if path.contains("memories/raw_memories.md") {
        MemoriesUsageKind::RawMemories
    } else if path.contains("memories/rollout_summaries/") {
        MemoriesUsageKind::RolloutSummaries
    } else if path.contains("memories/skills/") {
        MemoriesUsageKind::Skills
    } else {
        return None;
    };
    Some((kind, version))
}
