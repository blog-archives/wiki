# 外部链接设计约定

用途是中文知识文章的来源识别。风格：克制、清晰、紧凑；以「图标、文字、边界」建立识别。

沿用 `quartz.config.yaml` 的字体和浅深色主题，不新增字体或品牌色。正文链接使用 `--secondary`；边框使用 `--lightgray`；轻标签使用 `--highlight`；域名使用 `--darkgray`。深色主题通过同一组主题变量切换。

正文有 text / tag / pill 三档视觉强度。当前选择 pill：0.94em 字号、1.5 行高、1em 圆角、1px 边框，不叠加阴影。tag 圆角 5px；卡片 8px。行内图标 0.95em，箭头 0.7em，间距 0.3em。正文保留原始文字及强调，长标题允许换行，不省略来源信息。

卡片与来源行只用于配置启用后独占段落的链接。交互反馈为文字下划线和背景变化；键盘焦点使用清晰轮廓，不使用位移或动画。链接语义保持原生 anchor，装饰性图标对辅助技术隐藏。图标失败或没有 JavaScript 时呈现地球。

设计检查：无阴影、渐变、大封面或独立字体加载；沿用文章密度与主题，重点验证正文基线、窄屏换行、浅深色、键盘聚焦、图标失败回退。
