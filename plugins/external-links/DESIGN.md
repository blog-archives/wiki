# 外部链接设计约定

用途是中文知识文章的来源识别。风格：克制、清晰、紧凑；以「图标、文字、边界」建立识别。

沿用 `quartz.config.yaml` 的字体和浅深色主题，不新增字体或品牌色。正文链接使用 `--secondary`；边框使用 `--lightgray`；轻标签使用 `--highlight`；域名使用 `--darkgray`。深色主题通过同一组主题变量切换。

正文有 text / tag / pill 三档视觉强度。当前选择 pill：0.94em 字号、1.5 行高、1em 圆角、1px 边框，不叠加阴影。tag 圆角 5px；卡片 8px。行内图标 0.95em，箭头 0.7em，图标间距 0.3em。行内链接左右各留 0.25em（`--el-inline-space`），与相邻汉字或标点保持约一个空格的间隔。正文保留原始文字及强调，长标题允许换行，不省略来源信息。

站内链接沿用同一档 `style`（当前 pill）与前后间隔，前方放 `internalLogo` 指定的线性符号（默认 `note` 文档图标），不带箭头和域名，并覆盖 Quartz 默认的高亮底色。内外链因此共享边框与圆角语言，靠 favicon / 线性符号区分来源类型；符号随 `currentColor` 取色并沿用 1.6 描边，与地球、箭头同一套线性图形语言。`standaloneStyle` 的卡片与来源行只用于独占段落的外链，站内链接始终按行内样式渲染。

卡片与来源行只用于配置启用后独占段落的链接。交互反馈为文字下划线和背景变化；键盘焦点使用清晰轮廓，不使用位移或动画。链接语义保持原生 anchor，装饰性图标对辅助技术隐藏。图标失败或没有 JavaScript 时呈现地球。

设计检查：无阴影、渐变、大封面或独立字体加载；沿用文章密度与主题，重点验证正文基线、链接与相邻文字的前后间隔、站内链接不压过正文、窄屏换行、浅深色、键盘聚焦、图标失败回退。
