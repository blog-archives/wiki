## 项目介绍

题库系统是面向中小学生的在线刷题平台，老师出题、学生刷题都在上面。后端从需求拆解、接口设计到 Agent 落地最后上线维护由我独立负责。对比传统的 Web 服务，这个项目中最重要的是学习计划助手和出题助手两个 Agent 的实现，这两个场景的功能边界都很具体，所以采用预编排好的主线流程 + 关键环节使用 ReAct Agent 自主判断。

为了实现整套的 Agent 能力，将只读的数据查询封装成工具提供给模型调用，题目数据也提供了 filesystem mcp 允许模型操作指定的临时目录，所有产物经人工确认以后才会覆盖到真实题目数据目录。生成的数据按约定的结构化输出，会经程序做基础的存在性和重复性的校验以后再回传给模型做检查判断。中间过程出错或最后生成效果不过关也会一套按知识点划分的专题计划作为兜底。

最后我们还配套使用了 langfuse 用来观测，完整的 trace 能够定位到整个工作流程中是哪个节点、哪次循环、那侧工具调用慢或出错。
